# 《第十三扇门：失忆档案》游戏设计文档 v2

> v2.0（2026-10-05）。随版本推进更新。

## 一、剧情梗概

玩家在废弃地下研究所"回廊7号"的苏醒室醒来，失去全部记忆。房间里只有桌子、电脑、照片墙、保险箱和一扇打不开的门。墙上写着：**"你已经来过这里12次。"**

探索拼出真相：这里进行过记忆实验；玩家不是调查者，而是编号 **T-13 的实验对象**——"第十三扇门"实验通过让受试者在死亡回路中反复苏醒，测量的正是"记忆能否穿透循环"。

## 二、V0.1 苏醒室（10分钟Demo）布局

```
        北墙：[照片墙 x-3~0]      [门 x2.9~4.1 → 门后黑 vestibule]
        西墙：[墙字]   [桌子：电脑/键盘/便签 + 台灯点光]
        房中：[保险箱(照片墙下) 内藏门禁卡]
        南侧：[医疗床 + 撕下的便签]      出生点(0,0,3.5) 面朝北墙
```

## 三、V0.1 流程与谜题链

1. 醒来 → 提示操作；阅读墙上文字（"你已经来过这里12次。"）
2. 看桌上便签："保险箱：四个数字。那一年。"
3. 看电脑终端：T-13 档案片段 + "他的答案藏在照片里"
4. 看照片墙：四张照片，最后一张背面"1998年冬，最后一次团聚"
5. 拾取床上撕下的便签（入背包）
6. 保险箱输入 **1998** → 开箱 → 拾取门禁卡
7. 开门 → 触发时间循环：黑屏 → 第2次循环
8. 循环变化：墙字变"13次"、照片多出一个未知人影；Demo结束卡

## 四、时间循环规则（数据驱动）

规则序列化在场景对象的 `LoopObject.rules` 上（fromLoop + setActive/setText/setColor）：

| 对象 | Loop1 | Loop2 | Loop3(预留) |
|---|---|---|---|
| 墙字 | 12次 | 13次 | "别再数了。" |
| 照片墙 | 正常 | 多出人影 | 人影靠近 |
| 门 | 锁 | 锁（可再开） | — |

跨循环保留（记忆穿透）：背包物品、已开保险箱、剧情旗标。每循环重置：门复位、玩家回床。

## 五、整体游戏规模（V0.4/V0.5 落地）

5-8房间：苏醒室 → 监控走廊 → 实验室 → 档案室 → 控制室 → 地下区域 → 第十三扇门。循环上限4次；4结局（循环耗尽/逃离/真相/隐藏真结局）。

## 六、操作

左下摇杆移动；屏幕拖动转视角；右下【交互】按钮；右上【背包】。编辑器：WASD+右键拖动。

## 七、恐怖与演出原则

心理恐怖：低频环境音、远处声响、灯光事件、场景微妙变化；无跳脸实体。粒子预算≤200；单方向光+1台灯点光，全烘焙目标（V0.5前实时可接受）。

## 八、性能预算（中端机 60fps 目标 / 30fps 底线）

单帧 ≤150k 三角面、≤120 DrawCall；ASTC 6x6；音频 Vorbis；APK ≤150MB（V0.1 预期 ~25MB）。
