# 《第十三扇门：失忆档案》项目开发计划 v2

> v2.0（2026-10-05）：按制作人新版指令重构——文件全部收拢到 ZCode工作区、版本迭代制、URP 渲染。
> 类型：第一人称低多边形3D心理恐怖解谜（密室逃脱 + 时间循环 + 剧情推理）｜Android

## 一、目录结构（最高优先级规则）

```
D:\Agent工作区\ZCode工作区\
├── 第十三扇门_失忆档案\          ← 目录1：Unity工程本体 + APK
│   ├── Assets\                   Scripts/{Player,Interaction,Inventory,Puzzle,TimeLoop,Story,Save,UI,Audio}
│   │                             Editor\ Scenes\ Prefabs\ Models\ Materials\ Audio\ UI\ Data\
│   ├── Builds\                   APK 交付
│   └── Tools\                    build_door13.sh 流水线、日志
└── 第十三扇门_开发中心\          ← 目录2：项目管理资料（六大报告 + 设计文档 + 备份）
```

构建约束：安卓工具不支持中文路径 → Unity 会话一律经 ASCII 联接 `D:\TDM`（指向目录1）打开；工具链复用 `Unity开发环境\Android`（经 `D:\UBSAndroid` 联接）。

## 二、技术选型

| 项 | 决策 |
|---|---|
| 引擎 | Unity 2022.3.62f3c1 LTS（复用已有环境，零新装） |
| 渲染 | **URP 14.0.11**（v2 变更：由内置管线改为 URP，按新需求；不写自定义HLSL着色器，规避URP14着色器坑；MSAA 4x 由URP资产配置） |
| 脚本后端 | IL2CPP + ARM64 ｜ GLES3-only ｜ minSdk24/targetSdk34 ｜ Gamma 色空间 |
| 资源 | 纯自制：基本体低模 + 程序化贴图/音效，零下载 |
| 存档 | JSON → persistentDataPath，带版本号 |
| 冒烟测试 | 每版本必跑 batchmode 播放模式冒烟（含功能断言） |

## 四、V0.1 验收标准（10分钟可玩Demo）

进入房间→移动/转视角→观察（便签/电脑/照片墙/墙上文字）→拾取（撕下的便签）→破解保险箱密码（线索：便签+照片日期）→取得门禁卡→用卡开门→触发时间循环→场景变化（墙上"12次"→"13次"、照片多出人影）→循环2开始→Demo结束卡。

自动测试：编译0错误 + 播放冒烟（含功能断言：保险箱开/门开/循环重置/照片变化/墙字更新）+ APK构建成功。
